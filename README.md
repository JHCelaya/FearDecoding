# FearDecoding

Project Summary

This project analyzes ventral pallidum neural activity to decode fear-related behavioral states in rodents. Using firing rate data and suppression ratios during different cue conditions (danger, safety, uncertainty, reward), we built and evaluated multiple machine learning classifiers to predict fear responses. We applied feature selection to identify the most informative neurons and tested models including Random Forests, Support Vector Machines, and Logistic Regression. The Random Forest achieved the best performance (ROC AUC = 0.917), demonstrating that neural patterns can effectively distinguish between danger and safety trials. This work shows the feasibility of decoding emotional states from high-dimensional neural recordings.
